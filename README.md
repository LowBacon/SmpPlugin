# Minecraft SMP Plugin

A complete, feature-rich **Minecraft SMP plugin** designed for modern Minecraft servers running **Paper, Purpur, Spigot, and Bukkit**.

This plugin provides an all-in-one SMP experience with essential server systems, gameplay features, economy tools, player management, and quality-of-life improvements, reducing the need to install dozens of separate plugins.

## ✨ Features

* 🏠 SMP spawn and teleportation systems
* 💰 Economy and player money systems
* 🛒 Shops and player trading
* 📦 Auction House
* 🏆 Leaderboards and statistics
* 👤 Player management and profiles
* 🛡️ Server protection and moderation features
* 💬 Custom chat and messaging systems
* 🎁 Rewards and player progression
* ⚔️ SMP gameplay features
* 📊 Player statistics and tracking
* 🔧 Fully configurable settings
* 🌍 World and spawn management
* 🎨 Custom messages, formatting, and colors
* ⚡ Performance-focused and optimized
* 🔌 PlaceholderAPI support
* 🔐 Permission support
* 📁 Extensive configuration options

## 🚀 Compatibility

Designed to work with modern Minecraft server software:

* **Paper**
* **Purpur**
* **Spigot**
* **Bukkit**

The plugin is built with performance, compatibility, and server stability in mind.

## ⚙️ Configuration

Everything is designed to be easily configurable through YAML configuration files, including:

* Messages
* Permissions
* Economy settings
* Gameplay settings
* Rewards
* Commands
* Spawn settings
* GUI settings
* Feature toggles

You can enable or disable individual systems without having to modify the source code.

## 🧩 Commands

The plugin provides a large collection of SMP-related commands for players and administrators, including commands for:

* Spawn
* Economy
* Shops
* Auction House
* Statistics
* Leaderboards
* Player management
* Administration
* Configuration

Run `/smp help` in-game to view the available commands.

## 🔑 Permissions

The plugin includes a permission system designed to work with popular permission managers such as **LuckPerms**.

Permissions can be configured for individual commands and administrative features.

## 🛠️ Development

Built using **Java** with a modern Maven-based development environment.

### Requirements

* Java version supported by your Minecraft version
* Paper, Purpur, Spigot, or Bukkit server
* Maven for building from source

### Build

```bash
mvn clean package
```

The compiled plugin will be available in the `target/` directory.

## 📥 Installation

1. Download the latest release.
2. Place the `.jar` file inside your server's `plugins` folder.
3. Restart the server.
4. Configure the plugin inside its generated configuration folder.
5. Reload or restart the server after making configuration changes.
